# Los flowcharts mandan

La lógica de este proyecto se diseñó en diagramas antes que en código. Los diagramas están en el
board de Figma y transcritos en `docs/tecnico/`.

**Antes de modificar cualquier módulo, lee su documento de especificación.** Cada script cita en
su cabecera cuál es.

Si el código contradice al documento, el código es el bug. Si crees que el documento está mal,
**dilo en vez de cambiar el código**: los diagramas los mantiene el equipo, y una divergencia
silenciosa entre diagrama y código es exactamente lo que este proyecto quiere evitar.

Si un cambio requiere modificar el diagrama, señálalo explícitamente en tu resumen para que se
actualice el board.
